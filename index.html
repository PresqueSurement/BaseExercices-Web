      Télécharger le PDF ↓
      La compilation utilise vos packages personnels. Aucun compte ni clé GitHub n’est demandé dans le navigateur.
      Lancement depuis GitHub
      
    
      1. Copiez la sélection ci-dessous.
      2. Ouvrez GitHub et cliquez sur Run workflow.
      3. Collez la sélection dans demande, puis lancez Run workflow. Laissez request_id sur manuel.
      4. Ouvrez l’exécution terminée et téléchargez devoir-compile dans Artifacts.
      
    
    
      2. Ouvrir la compilation GitHub ↗
      
    
      Lancement direct et suivi depuis cette page
      Ce mode nécessite une clé GitHub limitée au dépôt BaseExercices, avec la permission Actions : Read and write. Elle est envoyée uniquement à api.github.com et conservée en mémoire le temps du suivi, jamais dans les fichiers publics ni dans le stockage du navigateur.
      Créer une clé limitée sur GitHub ↗
      Dans Repository access, choisissez Only select repositories → BaseExercices. Vérifiez Actions : Read and write, puis copiez la clé ici. Ne la partagez pas.
      
    
      
    
      Une compilation peut prendre plusieurs minutes. Le site de test reste public. Vos packages restent dans le dépôt privé ; aucun mot de passe GitHub ne doit être saisi sur cette page.
